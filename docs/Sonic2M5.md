# Sonic 2 milestone M5: Beta 4 (s2b4)

The reference is the improved disassembly of Sonic 2 Beta 4 (Esrael and Puto's, improved by Kurk and RepellantMold): https://github.com/desiresin/Sonic-2-Beta-4-Improved, kept outside this repository at `~/Projects/reference/s2b4-disasm` (`Sonic2B4.asm`, `Constants.asm`, `macros.asm`, data in `data/`, `levels/`, `artnem/`, `sound/` ...; `S2B4_Org.bin` is the ROM). M5 follows M4 (the pre-beta, tagged `S2PB`); the censor build was skipped (the user, 2026-11-13: it was tainted with a hacktro that made its decompilation harder), so s2b4 is M5.

## Title scene and demos (the user: "title scene changes such as demo files next")

* **Demo files: nothing to change.** The five recordings in s2b4 (`Demo_Green_Hill`, `Demo_Green_Hill_Miles`, `Demo_Hill_Top`, `Demo_Casino_Night`, `Demo_Chemical_Plant`) are byte for byte the port's `res/Demo` files (NAEHZ, SWEHZTails, NAHTZ, NAHPZ, NACPZ), which are the pre-beta's. `Demo_Index` has the same entries, and the title's order (`Demo_Mode_Level_Array`: Chemical Plant $D00, Emerald Hill $000, Casino Night $C00, Hill Top $700, four used) is the pre-beta's, with the same quirks (Emerald Hill's demo turns the second-player flag on; $600 would start the special stage).
* **Title screen data: nothing to change.** Wings and background art (`titlescr.nem`), Sonic and Miles (`sncmlscr.nem`), the 1P/2P menu sprites (`1p2pVs.nem`), the three Enigma maps and the palette are the pre-beta's, byte for byte; the music is $99, the demo timer $178, the level select code the same.
* **Code differences found in the title scene** (`TitleScreen` .. `PlayLevel`), to port when M5's other parts are in: the screen starts by playing $FD (stop); it clears the two-player results table (`Results_Data_2P`, 12 words of $FFFF) on entry; the level-select flags `$FFFFFFD0` and `$FFFFFFD2` are set as words ($101 each: four flags on) where the pre-beta sets one byte; the start sound of a level, a demo and the level select is `Play_Sfx $F9` where the pre-beta plays $E0 (check the s2b4 ids: they follow its own sound table); `PlayLevel` and the special stage entry of the level select also set `$FFFFFEC6` to 3 (a second counter beside the lives: continues), clear `Current_Special_Stage` and the emerald lists (`$FFFFFFB0`, `$FFFFFFB2`, `$FFFFFFB6`) and `$FFFFFED0`/`$FFFFFED2`/`$FFFFFED6`. The level select array is the pre-beta's (Hidden Palace still disabled: the port keeps its own, as the user decided for M4).

### The session flow (the user, 2026-11-13)

* 2PMenu: LOCAL SPLITSCREEN, HOST SESSION, JOIN SESSION. **After a session connects it goes to the four-box zone screen, as the local choice does.**
* **Finding the host works as Palworld's password sessions do**: the host announces the session on the local network (UDP broadcast, port `NETPLAY_DISCOVERY_PORT` 47831, every half second, the WebSocket port and a *tag* of the code: 8 bytes of a hash, never the code), the guest types the code, searches for an announcement with its tag and joins the address it came from, with the code as the password (the handshake of `NetPlay.h`). Engine: `NetPlay_JoinByCode`, status `NETPLAY_SEARCHING`, `NetPlay_SetDiscoveryPort`; tests `Netplay_TheGuestFindsTheHostByTheCode` and `..AWrongCodeOrAnotherGameFindsNobody`. It is for the local network (a host past a router is not found).
* **Screens the user will have designed (by Claude, from the final game's menu look):** (1) the **host's code screen** with a "please wait" message, (2) **please wait (guest)**, (3) **please wait (loading)**, and (4) a **network timeout screen** that asks the player to press any button to return to the 2 player menu.

## The versus flow (2026-11-14)
The structure (the user): zone menu -> [Please Wait] -> title card -> act -> [Please Wait] -> act results -> [Please Wait] -> title card (next act) -> act -> ... with a special stage as the tie breaker -> zone menu -> (no zones left) [Please Wait] -> global results -> the Sega screen. `[Please Wait]` is `S2Menu/TwoPLoading`, shown in online mode only.
**What happens during Please Wait (the user):** the two games talk to each other: they negotiate the level starting (the host's choice, both ready) or, after an act, exchange the game stats of both players so that both decide the same winner for the round (the five categories). **Once the title card is loaded the two games are in lockstep and the players are active in the level** (so the netplay start message and the first `NetPlay_Frame` belong to the end of the title card, not to the level's first frame; the card itself runs on each machine as its own).
Beta 4's own flow (read from `Versus_Mode_Results`, game mode $18, pages in `$FFFFFF10`): page 0 act results (after each act; the first act goes on to the second; after the second the zone's winner is the player who won more acts: a winner goes to page 1, a tie to the special stage), page 1 level (zone) results (-> the zone menu while any zone has an act unplayed, else page 2), page 2 global results (-> the Sega screen), page 3 special stage results (a zone's tie breaker -> page 1; the special stage box has three rounds, then page 4), page 4 all special stage results (-> as page 1). The kept data is `Results_Data_2P` (4 zones x 3 entries, a byte per player: the categories won, $FFFF unplayed, $FFFE game over) and the act's stats of both players (score, time, rings, items, total rings).
Built: `src/VersusFlow.{h,c}` (the data and the transitions, tested in `tests/test_versusflow.c`). ## The egg prison, Beta 4's (2026-11-14)

Standing on the button (it goes down 8 pixels, the clock stops) throws the lid off with an explosion without an animal, 29 frames later the capsule opens (frames 0-3), eight animals in a row come out and more every 8th frame for three seconds, and when no animal is left `GotThroughAct` makes the end card.
