# Sonic 2 milestone M5: Beta 4 (s2b4)

The reference is the improved disassembly of Sonic 2 Beta 4 (Esrael and Puto's, improved by Kurk and RepellantMold): https://github.com/desiresin/Sonic-2-Beta-4-Improved, kept outside this repository at `~/Projects/s2b4-disasm` (`Sonic2B4.asm`, `Constants.asm`, `macros.asm`, data in `data/`, `levels/`, `artnem/`, `sound/` ...; `S2B4_Org.bin` is the ROM). M5 follows M4 (the pre-beta, tagged `S2PB`); the censor build was skipped (the user, 2026-11-13: it was tainted with a hacktro that made its decompilation harder), so s2b4 is M5.

## Title scene and demos (the user: "title scene changes such as demo files next")

* **Demo files: nothing to change.** The five recordings in s2b4 (`Demo_Green_Hill`, `Demo_Green_Hill_Miles`, `Demo_Hill_Top`, `Demo_Casino_Night`, `Demo_Chemical_Plant`) are byte for byte the port's `res/Demo` files (NAEHZ, SWEHZTails, NAHTZ, NAHPZ, NACPZ), which are the pre-beta's. `Demo_Index` has the same entries, and the title's order (`Demo_Mode_Level_Array`: Chemical Plant $D00, Emerald Hill $000, Casino Night $C00, Hill Top $700, four used) is the pre-beta's, with the same quirks (Emerald Hill's demo turns the second-player flag on; $600 would start the special stage).
* **Title screen data: nothing to change.** Wings and background art (`titlescr.nem`), Sonic and Miles (`sncmlscr.nem`), the 1P/2P menu sprites (`1p2pVs.nem`), the three Enigma maps and the palette are the pre-beta's, byte for byte; the music is $99, the demo timer $178, the level select code the same.
* **Code differences found in the title scene** (`TitleScreen` .. `PlayLevel`), to port when M5's other parts are in: the screen starts by playing $FD (stop); it clears the two-player results table (`Results_Data_2P`, 12 words of $FFFF) on entry; the level-select flags `$FFFFFFD0` and `$FFFFFFD2` are set as words ($101 each: four flags on) where the pre-beta sets one byte; the start sound of a level, a demo and the level select is `Play_Sfx $F9` where the pre-beta plays $E0 (check the s2b4 ids: they follow its own sound table); `PlayLevel` and the special stage entry of the level select also set `$FFFFFEC6` to 3 (a second counter beside the lives: continues), clear `Current_Special_Stage` and the emerald lists (`$FFFFFFB0`, `$FFFFFFB2`, `$FFFFFFB6`) and `$FFFFFED0`/`$FFFFFED2`/`$FFFFFED6`. The level select array is the pre-beta's (Hidden Palace still disabled: the port keeps its own, as the user decided for M4).

### How s2b4's 2P VS scene works (read from `Versus_Mode_Menu`, game mode $1C; `Sonic2B4.asm` line ~9036)

The port has no such screen yet (the title's 2P choice goes straight to a level). s2b4's, in order:
* **Set-up:** fade out, plane A at $C000 and B at $E000 (registers $8230, $8407), 40 cells wide; art: `Menu_Font` at tile $210, `Menu_Frame` at $260, `Level_Icons` at $280 (Nemesis); the **background plane** is `mapeni/VsMenuBg.eni` (40x28, a repeating six-tile stripe), decoded at base $6000 (palette line 3) and drawn at $6000 (plane B); the text plane is `vs_menu.eni` at base $60, drawn twice (the second at base $2060: the same text on the other palette line, for the selected entry) and `vsmenu2.eni` (a run of sequential tiles: the icon frames) at base $80. Palette $26, music $91 (the menu theme), the demo timer $707 (the menu times out).
* **The zone menu is four boxes**, picked with the d-pad (Up/Down toggle bit 1 of `Current_Zone_2P`, Left/Right bit 0; two player pads are read: `Ctrl_1_Press | $FFFFF607`): **Emerald Hill ($0000), Mystic Cave ($0B00: Dust Hill's slot), Casino Night ($0C00), Special Stage** (`loc_989E`: $0, $B00, $C00, $FFFF); each box has its name mapping (`Map_Emerald_Hill`, `Map_Mystic_Cave`, `Map_Casino_Night`, `Map_Special`) and its icon (`Map_Zone` or `Map_Stage`; the icon's palette comes from `lvsicons.pal`, one line of 16 colours per zone). The box shows the results of the zone from `Results_Data_2P` (3 words each: two player scores and a draw count) if it has been played.
* **Start** (either pad) takes the choice: a zone sets `Level_Id` and `Two_Player_Flag` = 1 and goes to game mode $C; the Special Stage entry goes to mode $10 with the flag set. An already-played zone whose results are non-zero plays the "can't pick" sound ($ED) and stays.
* Files in s2b4's `mapeni/`: `Vs_Menu`, `VsMenu2`, `VsMenuBg` (this scene), and `VsActRes`, `VsAll_SS`, `VsGblRes`, `VsLvlRes`, `Vs_SSRes` (the results scenes: game mode $18).

* **The block at the bottom of both** (rows 21-27, tiles $4D-$67 on palette line 3, mirrored) is the final game's level-select foreground, left in by the user's generator: **ignored** (the user: it corrects itself when the level select comes in with the later milestones). The background is `VsMenuBg.eni`, as above, kept for all the menus.

### The session flow (the user, 2026-11-13)

* 2PMenu: LOCAL SPLITSCREEN, HOST SESSION, JOIN SESSION. **After a session connects it goes to the four-box zone screen, as the local choice does.**
* **Finding the host works as Palworld's password sessions do**: the host announces the session on the local network (UDP broadcast, port `NETPLAY_DISCOVERY_PORT` 47831, every half second, the WebSocket port and a *tag* of the code: 8 bytes of a hash, never the code), the guest types the code, searches for an announcement with its tag and joins the address it came from, with the code as the password (the handshake of `NetPlay.h`). Engine: `NetPlay_JoinByCode`, status `NETPLAY_SEARCHING`, `NetPlay_SetDiscoveryPort`; tests `Netplay_TheGuestFindsTheHostByTheCode` and `..AWrongCodeOrAnotherGameFindsNobody`. It is for the local network (a host past a router is not found).
* **Screens the user will have designed (by Claude, from the final game's menu look):** (1) the **host's code screen** with a "please wait" message, (2) **please wait (guest)**, (3) **please wait (loading)**, and (4) a **network timeout screen** that asks the player to press any button to return to the 2 player menu.

### The user's other session screens (added 2026-11-13, in `res/S2Menu/`)

Read through the menu font (tile $1E-$37 A-Z, $10-$19 0-9, $1A space, $1D '.'; plane 40x28; text on palette lines 1 (`$2xxx`), 0 (`$00xx`) and 3 (`$6xxx`)):
* `TwoPHostWait`: "2 PLAYER VERSUS", the label **SESSION CODE** (row 6, palette line 0), the code field (rows 8-9: two rows of two groups of five '.' boxes, columns 13-17 and 19-23), the box frame, and **PLEASE WAIT** (rows 13 and 16, palette line 3: "PLEASE" and "WAIT").
* `TwoPGuestWait`: the title, **LOOKING FOR SESSION** (row 7), the box frame, PLEASE WAIT; rows 5-6 and 8-9 have blocks of tile $6000 (a bar area the code can animate).
* `TwoPLoading`: the same frame and PLEASE WAIT; the label row 7 is blank (the game writes it: LOADING).
* `TwoPRefused`: **CONNECTION REFUSED** (row 4), the frame, **PRESS ANYTHING TO CONTINUE** (rows 16 and 19). It is for **a connection refused error** (the user, 2026-11-13): the engine closes the session with the host's refusal (`deny`: wrong code, a second guest, another game) or the socket's own "connection refused" error. Anything else that ends a search, a wait or a handshake without a connection (nobody found in time, the host never answered, the other side went away) is the **time out** screen.
* `TwoPTimeOut`: **SESSION TIME OUT** (row 4), the same frame and text: any button returns to the 2 player menu.
The zone menu's assets from s2b4 are in too: `MenuFont`, `MenuFrame`, `LevelIcons` (Nemesis), `SonicMiles` (the animation), `VsMenuBg`, `VsMenu`, `VsMenu2`, palettes `VersusMenu` ($26) and `LevelIcons`. Nothing draws them yet.

**Music for all these menus (the user, 2026-11-13): the Level select / Options theme** (`mus_Menu`, $91), from the session menu through the code, wait, loading, refused and time-out screens to the zone menu (s2b4's zone menu plays $91 already). It starts on entering the first of them and keeps playing across them (no restart between screens).

**The zone menu will get a second page of four more boxes later** (the user, 2026-11-13): build it data-driven (a table of boxes, four to a page, a page number) from the start. Page 2 is where the versus-only Hidden Palace act 2 goes (see the HPZ versus plan).
